# Contributing to RLP

Thank you for your interest in contributing to the Reward Layer Protocol.

## Ways to Contribute

### Specification Feedback

- Open an issue to discuss proposed changes
- Submit PRs for clarifications or corrections
- Share implementation experiences that reveal spec ambiguities

### Implementations

If you've implemented RLP, please:
- Open a PR to add your implementation to the README
- Share any spec issues you encountered

### Documentation

- Improve explanations
- Add examples
- Fix typos

## Process

1. **Discuss first** — For significant changes, open an issue before submitting a PR
2. **Keep changes focused** — One logical change per PR
3. **Follow conventions** — Match existing formatting and style

## Specification Changes

Changes to SPECIFICATION.md require:
- Clear rationale
- Consideration of backwards compatibility
- Discussion period for community feedback

## Code of Conduct

Be respectful and constructive. We're building an open standard that benefits everyone.
